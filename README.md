# Менеджер товаров (Fullstack)

Полнофункциональное Fullstack приложение для управления каталогом товаров с собственным API, базой данных и современным фронтендом.

## ✨ Функциональность

- 📦 **Просмотр товаров** - отображение списка товаров в виде красивых карточек
- ➕ **Добавление товаров** - создание новых товаров через интуитивное модальное окно
- ✏️ **Редактирование товаров** - изменение существующих товаров с валидацией
- 🗑️ **Удаление товаров** - удаление товаров с подтверждением
- 🔍 **Поиск товаров** - поиск по названию, описанию и категории
- 🔄 **Сортировка** - сортировка по цене и рейтингу (возрастание/убывание)
- 📱 **Адаптивный дизайн** - корректное отображение на всех устройствах
- ⚡ **Быстрая загрузка** - оптимизированная производительность
- 🎨 **Современный UI** - красивый и интуитивный интерфейс

## 🛠 Технологии

### Frontend

- **React 18** - современная библиотека для создания пользовательских интерфейсов
- **TypeScript** - типизированный JavaScript для безопасности кода
- **Vite** - быстрый инструмент сборки и разработки
- **Axios** - HTTP клиент для работы с REST API
- **CSS3** - современная стилизация с Flexbox и Grid

### Backend

- **Node.js** - серверная платформа JavaScript
- **Express.js** - веб-фреймворк для Node.js
- **SQLite** - легковесная база данных
- **Express Validator** - валидация данных
- **CORS** - настройка кросс-доменных запросов
- **Helmet** - безопасность HTTP заголовков

### Инструменты

- **Concurrently** - запуск нескольких процессов
- **Nodemon** - автоматическая перезагрузка сервера
- **ESLint** - линтер для поддержания качества кода

## 🚀 Установка и запуск

### Быстрый старт

1. **Клонируйте репозиторий:**

```bash
git clone https://github.com/GoncharovMaksim/AvtomatServiseStage2.git
cd AvtomatServiseStage2
```

2. **Установите все зависимости:**

```bash
npm run install:all
```

3. **Инициализируйте базу данных:**

```bash
npm run init:db
```

4. **Запустите Fullstack приложение:**

```bash
npm run dev
```

5. **Откройте браузер:**

- Frontend: `http://localhost:3000`
- Backend API: `http://localhost:5000/api`

### Отдельный запуск компонентов

**Только фронтенд:**

```bash
npm run dev:frontend
```

**Только бэкенд:**

```bash
npm run dev:backend
```

## 📦 Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

## 🔧 Дополнительные команды

```bash
npm run preview    # Предварительный просмотр сборки
```


## 🔌 API

Приложение использует собственный REST API с SQLite базой данных:

| Метод    | Endpoint                   | Описание                   |
| -------- | -------------------------- | -------------------------- |
| `GET`    | `/api/products`            | Получение списка товаров   |
| `GET`    | `/api/products/{id}`       | Получение товара по ID     |
| `POST`   | `/api/products`            | Создание нового товара     |
| `PUT`    | `/api/products/{id}`       | Обновление товара          |
| `DELETE` | `/api/products/{id}`       | Удаление товара            |
| `GET`    | `/api/products/categories` | Получение списка категорий |
| `GET`    | `/api/health`              | Проверка состояния API     |

**Base URL:** `http://localhost:5000/api`

Подробная документация API доступна в файле [backend/API.md](backend/API.md)
