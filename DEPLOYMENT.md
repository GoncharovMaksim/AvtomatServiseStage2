# Инструкции по развертыванию

## 🚀 Быстрый старт

### Локальная разработка

1. **Клонируйте репозиторий:**

```bash
git clone <repository-url>
cd AvtomatServise
```

2. **Установите зависимости:**

```bash
npm install
```

3. **Запустите приложение:**

```bash
npm run dev
```

4. **Откройте браузер:**
   Перейдите по адресу `http://localhost:3000`

### Сборка для продакшена

1. **Соберите проект:**

```bash
npm run build
```

2. **Предварительный просмотр:**

```bash
npm run preview
```

## 🌐 Развертывание на хостинге

### Vercel

1. Подключите репозиторий к Vercel
2. Настройки сборки:
   - Build Command: `npm run build`
   - Output Directory: `dist`
   - Install Command: `npm install`

### Netlify

1. Подключите репозиторий к Netlify
2. Настройки сборки:
   - Build Command: `npm run build`
   - Publish Directory: `dist`

### GitHub Pages

1. Установите gh-pages:

```bash
npm install --save-dev gh-pages
```

2. Добавьте в package.json:

```json
{
  "scripts": {
    "predeploy": "npm run build",
    "deploy": "gh-pages -d dist"
  }
}
```

3. Разверните:

```bash
npm run deploy
```

## 🐛 Отладка

### Проверка логов

```bash
# Запуск с подробными логами
DEBUG=vite:* npm run dev

# Проверка сборки
npm run build -- --debug
```

### Частые проблемы

1. **Ошибка CORS:**

   - Проверьте настройки API
   - Убедитесь, что API поддерживает CORS

2. **Ошибка загрузки товаров:**

   - Проверьте подключение к интернету
   - Убедитесь, что API доступен

3. **Проблемы со стилями:**
   - Очистите кэш браузера
   - Перезапустите dev сервер

## 🆘 Поддержка

При возникновении проблем:

1. Проверьте логи в консоли браузера
2. Убедитесь, что все зависимости установлены
3. Проверьте версии Node.js (рекомендуется 18+)
4. Очистите кэш и переустановите зависимости

```bash
# Очистка и переустановка
rm -rf node_modules package-lock.json
npm install
```
